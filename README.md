# Job Analytics Dashboard

This project is an interactive Tableau dashboard created to analyze job market trends using real-world job data. The dashboard helps users understand salary ranges, company sizes, required skills, qualifications, work types, experience levels, and job preferences across different countries and companies.

## Features

* Company-wise job analysis
* Salary range insights
* Experience level comparison
* Skills and qualification analysis
* Work type and preference visualization
* Country-based job trends
* Interactive filters and dashboards

## Tools Used

* Tableau
* Visual Studio Code
* Kaggle Dataset
* CSV Dataset
* Data Visualization Techniques

## Dashboard Insights

The dashboard provides visual insights into:

* High-paying job roles
* Popular skills in demand
* Preferred qualifications
* Company hiring patterns
* Remote and on-site work trends

## Dataset Source

The dataset used in this project was downloaded from Kaggle for educational and analytical purposes.
Dataset link:https://www.kaggle.com/datasets/ravindrasinghrana/job-description-dataset

## Project Purpose

The main goal of this project is to simplify job market analysis through interactive visualizations and help users make data-driven career decisions.
